# Arena Coach — releases

Installers for **Arena Coach**, a Windows companion for League of Legends Arena.

Download the latest **ArenaCoach-Setup-x.y.z.exe** from [Releases](https://github.com/dop-amine/arena-coach-releases/releases/latest) and run it (per-user install, no admin prompt). Installed copies check this page and offer updates automatically.

Windows may warn about an unknown publisher (the installer is not code-signed yet): *More info → Run anyway*.
